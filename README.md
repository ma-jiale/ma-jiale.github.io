# ma-jiale.github.io

Jiale Ma 的个人主页，使用原生 HTML、CSS 和 JavaScript，适用于 GitHub Pages。

## 文件

- `index.html`：页面结构和默认中文内容。
- `styles.css`：颜色、字体、间距和移动端布局。
- `script.js`：中英文文案、语言切换和语言偏好保存。

## 预览与修改

可以直接用浏览器打开 `index.html`。开发时也可使用任意静态文件服务器预览仓库根目录，无需安装项目依赖或构建。

修改文案时，请同步更新 `script.js` 中的语言字典和 `index.html` 中的默认中文内容。当前关注区域刻意留空，待有真实内容后再填写。

## GitHub Pages

审核页面后，可将这些文件提交并推送到 GitHub。在仓库 Settings → Pages 中选择从分支部署，并选择存放页面文件的分支和根目录 `/ (root)`。本版不包含自动发布操作。
